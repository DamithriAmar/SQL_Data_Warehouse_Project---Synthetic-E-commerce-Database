# SQL_Data_Warehouse_Project---Synthetic-E-commerce-Database
<h2>Overview</h2>
This project aims to build a data warehouse using data from a synthetic E-commerce datasets.</br>
<b>Note:</b> Find details of the dataset & download the dataset at: </br><a href>https://www.kaggle.com/datasets/generaterealdata/synthetic-ecommerce-database?resource=download</a></br>

<h2>Project Objectives</h2>
Cleansing and organizing raw data to create a analytics ready datawarehouse.</br>

<h2>Project Specifications</h2>
<b>Data Sources: </b>7 CSV files downloaded from the above mentioned source.</br>
<b>Data Quality: </b>Clean & resolve data quality issues prior to analysis.</br>
<b>Integration: </b>Combine all the data sources into a single data model.
